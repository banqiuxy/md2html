# 示例章节

这是一个用来演示渲染效果的 Markdown 文件，运行 `python build.py` 后即可在浏览器中查看。

## 一、段落与行内格式

普通段落中可以使用**加粗**强调重点，也可以用*斜体*表示轻声的补充说明。行内代码如 `python build.py` 会以等宽字体显示。

段落中还可以放置[外部链接](https://example.com)，链接在新标签页打开。

---

## 二、代码块

用三个反引号包裹代码块，并标注语言：

```python
def build(chapters):
    payload = json.dumps(chapters, ensure_ascii=False)
    return template.replace("{{NOVEL_DATA}}", payload)
```

没有标注语言时按纯文本显示：

```
阅读进度与设置仅保存在本机
```

## 三、引用

> 用于引述他人的话，或突出强调一段内容。
> 引用块中的多行会合并显示。

## 四、列表

无序列表：

- 左侧目录列出全部章节
- 全文搜索支持关键词高亮
- 阅读进度与位置自动保存
- 支持字号、行距与主题切换

有序列表：

1. 把 Markdown 文件放进 `content` 目录
2. 运行 `python build.py`
3. 打开 `index.generated.html`

## 五、表格

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--content` | Markdown 文件或目录 | `content/` |
| `--split` | 按标题拆分成多章 | 关闭 |
| `--title` | 覆盖书名 | 配置文件 |
| `--force` | 覆盖已有输出 | 关闭 |
